# c001apk-Revived · Pre-release

c001apk-compose 现更名为 **c001apk-Revived**。本次为预发布版本，以下是相较 [244-9636cd4](https://github.com/frisk1127/c001apk-Revived/releases/tag/244-9636cd4) 的主要变化。

## 新增

- **新图标**：默认使用 Revived 图标，可在“设置 → 主题 → 应用图标”切换回原版。两种图标均支持系统取色和深浅模式，新图标保留双色折角。
- **收藏备份**：本地收藏支持导出、导入 JSON 文件，导入时自动合并去重并保留收藏时间。入口在“消息 → 本地收藏 → 右上角菜单”。[#15](https://github.com/frisk1127/c001apk-Revived/issues/15)
- **首页回顶**：发布按钮上方新增回顶按钮，跟随滚动显隐，支持平滑回顶。
- **板块排序**：首页板块在原有显示开关基础上增加拖动排序。
- **搜索链接**：支持酷安搜索链接跳转，兼容编码后的关键词。

## 体验改进

- 横屏首页全宽显示，打开动态后切换为左右双栏，返回后恢复全宽，并加入展开、收起动画。
- 修复页面返回动画缺失，优化回复面板、键盘、表情及图片选择器的切换动画。
- 改进回复对象头像和回复关系展示，调整“查看全部评论”入口。
- 为收藏、取消收藏、拉黑、删除等操作补充结果提示。

## 问题修复

- 修复评论提示“接口异常，请尝试升级到新版酷安”、无法正常加载的问题。[#19](https://github.com/frisk1127/c001apk-Revived/issues/19)
- 修复通过帖子链接冷启动应用时的闪退。[#16](https://github.com/frisk1127/c001apk-Revived/issues/16)
- 修复横屏首页在“动态／应用”之间反复切换、板块与内容错位的问题。
- 修复返回按钮和首页标签出现异常焦点高亮的问题。
- 改进评论文字区域的拖动手势，减少与列表滚动的冲突。
- 修复图片并发加载可能造成的缓存损坏。

## 升级说明

应用包名未变，使用相同签名的更高版本可直接覆盖安装，保留收藏和设置。更名前后导出的收藏备份也可继续使用。

本版仍处于测试阶段。遇到问题请在 [Issues](https://github.com/frisk1127/c001apk-Revived/issues) 中附上版本号、机型、Android 版本和复现步骤。
